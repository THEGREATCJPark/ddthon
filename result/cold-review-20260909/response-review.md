# 응답 품질 검토 — 기능 성공과 별도 판정

판정: 기능3건 PASS / 사용자 설명은 개선 필요. 원하는 사내환경 표시는 제품 CLI에서 P1 2/2 확인됐지만 Agent 설명은 일관되지 않았다. 문구를 통과시키기 위한 추가 프롬프트는 주지 않았다.

## 수용 가능한 부분

- P0는 기존 작업 Python을 유지하고 실제 공급 실패·Skill 적용·독립 설치 확인·reuse1을 보고했다. 실패 원인을 실제로 발생하지 않은 proxy 오류로 꾸미지 않았다.
- P1 두 건 모두 원본 무변경, NO_MATCH 뒤 새 접근·업무 계산·차트, 환경 절차 후보1/reuse0. 후보를 게시된 Skill로 말하지 않았고 사람 승인/게시를 대신 만들지 않았다.
- 제품 출력은 두 번 모두 `작업 환경: 사내환경 · NASCA(가상) (작업 공간에 제공된 환경 정보)`였다. 이 표시는 진단 결과가 아닌 제공된 환경 정보라고 명시했다.
- 첫 Agent는 `작업 파일과 사내환경(NASCA 가상) 컨텍스트를 확인했습니다`라고 안내했다. 암호를 요구하지 않았고 실제 암호화 문서 형식을 확인한 뒤 접근 방법을 바꿨다.

## 실제 개선 사항

1. **한국어 일관성**: 첫 P1도 중간에 영어1문장이 있었고, 두 번째 P1은 대부분의 진행 설명이 영어였다. 두 번째는 Agent 설명에서 사내환경/NASCA 명칭을 언급하지 않았다(CLI에는 출력됨). 현재 C9의 한국어 지침이 실사용에서 일관되게 지켜지지 않는다.
2. **사용자에게 불필요한 내부 설명**: P0는 `제품 CLI`를3회 언급하고 완료 안내에 `pip_exit`, `counted/reason`, `candidate_delta`, run_id와 합성 지원 범위를 길게 열거했다. P1은 procedure schema, artifact, 필드명·숫자 좌표 정정을 매번 설명했다. 거짓은 아니지만 일상적인 업무 완료 안내보다는 개발 진단 보고서에 가깝다. 실제 도구 원문은 유지하고 사용자 설명을 줄이는 편이 맞다.
3. **입력 계약 사용성**: P1 첫 실행은 procedure/task-mapping 형식3회, 두 번째는4회 재시도했다. 두 번째에는 UsedRange 상대 A/D를 절대 B/E로 잘못 이해했다가 수정했다. 잘못된 입력은 제품이 거절했고 최종값은 정확했다. 계약 도움말의 필드·자료형·절대 좌표 규칙을 명확히 하면 정답 데이터를 주지 않고도 줄일 수 있는 마찰이다.
4. **관찰과 추정 구분**: 잠금 파일만으로 Excel이 현재 열려 있다고 확정한 문장은 과도하다. 잠금 파일은 단서이고 실제 대상 워크북 attach로 확인해야 한다. OLE header만으로 암호화나 특정 보안제품을 단정하는 표현도 피해야 한다. 실제 시험 조건이 암호화였다는 사실과 Agent가 확보한 근거는 구분한다.
5. **차트 전달**: 두 번 모두 PNG 생성과 Agent의 이미지 Read는 확인했다. 하지만 최종 답변은 `위 차트`라고 하면서 명시적인 chart_ref 링크를 주지 않았다. Headless stream 테스트로 실제 사용자 Claude 창에서 차트가 보였다고 주장할 수 없다. 사용자가 열 수 있는 실제 PNG 경로를 결과에 연결하는 것이 더 확실하다.

## 다음 최소 수정 후보 — 아직 미구현

C9와 기존 run-p1 도움말을 대상으로 (a) 사용자 언어 유지·짧은 업무 결과 안내, (b) 제공 환경 설명/관찰/추정 분리, (c) JSON 계약과 절대 좌표 규칙 안내, (d) 실제 차트 링크 전달을 정합화하는 것이 우선이다. 고정된 성공 대사나 특정 열/시트/예측값을 넣지 않는다. 현재 테스트 소스는 끝까지 고정했고 이 검토에서 제품/C9를 바꾸지 않았다. 수정 시 기존 AI-DLC 최소 Code Plan에 반영하고 해당 Cold만 재검증한다.

정상 탐색 대기와 결함을 구분: `NEEDS_AGENT_DISCOVERY`/`NEEDS_TASK_MAPPING`의 exit2가 Claude tool error로 기록될 수 있지만 의도된 제어 흐름이다. 오류 개수를 그대로 실패 횟수라고 부르지 않는다. 권한 거절은 headless dontAsk 설정의 영향도 있다. 기록된 첫 시도를 없애거나 허용 범위를 몰래 넓히지 않았다.
