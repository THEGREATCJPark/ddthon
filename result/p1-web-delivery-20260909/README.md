## 웹 반영 요청

1. 기존 P1 시연 영역에 MP4 재생과 원본 패키지 다운로드를 연결합니다. 배포 도구가 public 디렉터리를 요구하면 담당자가 필요한 파일만 복사합니다.
2. 대표 실행 로그는 3회차 응답을 먼저 보여주고 전체 공개 로그를 펼쳐 볼 수 있게 연결합니다.
3. 영상과 로그는 **서로 다른 실제 실행**입니다. 영상은 수동 Cold 시연(사람 승인 → 독립 Replay → 게시, 커밋 `e302bf2`), 로그는 별도 자동 실행 3회차(업무 완료·후보 생성, 게시 미실행)로 각각 표기합니다.
4. 영상의 90초는 편집 길이입니다. 3회차 업무 완료 110.539초(1분 50.5초)와 혼용하지 않습니다. 3회차 최종 응답 완료는 127.155초입니다.
5. 영상의 공개 Skill 1→2는 신규 게시이며 재사용 +1이 아닙니다. Warm 재사용이나 토큰 절감의 증거로 바꾸지 않습니다.
6. `actual-trend.png`는 대표 로그 3회차의 차트입니다. 영상에서 촬영한 차트라고 표시하지 않습니다.
7. 화면 원문과 실제 실패·수정 흔적을 유지합니다. 편집 설명과 평가 데이터의 화면 확인/Agent 보고 구분을 보존합니다.

## 확인 범위

- 두 원본 ZIP의 SHA-256 및 크기: `source-archives.json`.
- 내부 manifest에 기재된 23개 파일 SHA-256 일치.
- 텍스트의 일반적인 자격증명 패턴 검사 및 제공된 증거 화면 11장 육안 확인. 새 검출 없음. 영상 전체 프레임 보안 감사나 재생 검증을 수행했다는 의미는 아닙니다.
- 영상 패키지는 사용자 이름·작업 경로를 마스킹하지 않은 제공 원본입니다. 대표 로그는 공개용 마스킹본입니다.
- 웹 구현·브라우저 재생·실제 배포 검증은 웹 담당자가 수행합니다.
