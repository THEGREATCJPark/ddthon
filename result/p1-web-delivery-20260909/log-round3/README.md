## 파일 구성과 편집 내역

- `responses.public.md`: 실제 Agent 답변, 개인 로컬 경로만 `<WORKSPACE>` 등으로 치환.
- `transcript.public.md/json`: 사용자 최초 요청·환경 단서와 실제 도구 호출/결과 포함. 비공개 사고·무관 메타데이터·이미지 바이너리를 제외하고 반복 bootstrap Skill 본문을 생략. 실행 오류를 삭제하거나 결과를 새로 쓰지 않음.
