# 프로젝트 평가 준비

이 파일은 프로젝트 지침이며 공식 AI-DLC v1.0.1 규칙의 일부가 아니다.

- 개발 요청 시 `README.md`와 `EVALUATION.md`를 읽고 공식 AI-DLC 절차에 따라 요구사항부터 진행하거나 실제 기록에서 재개한다.
- 평가 요약을 공식 원문으로 단정하지 않는다. 배점·제출 조건의 확인 여부를 구분한다.
- P0/P1은 검토할 후보이며 구현·승인 완료 상태가 아니다. 팀 인원·역할·Unit·기술 스택·일정을 미리 확정하지 않는다.
- 실제 AI-DLC 결정과 실행 증거를 보존하고 README에서 연결한다. 준비 문서를 완료된 개발 산출물로 취급하지 않는다.
- 실행 방법, 실제 스크린샷, 재실행 결과도 완료 기준에 포함한다. 검증하지 않은 결과는 `NOT_RUN`으로 표시한다.
- 합성 데이터·초기 예시 이력과 실제 사용 실적을 구분한다. 업무 원문과 인증정보는 공유 Skill 및 제출 증거에서 제외한다.
- 공식 `CLAUDE.md`와 `.aidlc-rule-details/`의 원문을 프로젝트 요구에 맞춰 덮어쓰지 않는다.
- 설정만 요청한 경우 제품 구현, 승인 기록, 스크린샷, 테스트 성공 결과를 미리 생성하지 않는다.
