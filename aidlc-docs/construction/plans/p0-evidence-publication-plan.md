1. 추가 ZIP은 데이터로만 읽는다. 포함된 실행기/patch는 실행하지 않는다. 전체 payload/입력/토큰 합계/독립 검증을 대조한다.
2. 선정은 추가 연속4/5/6회 전체로 한다. 결과·속도·토큰에 따른 선별은 하지 않는다. 기존1/2/3 포함 전체6회 이력도 공개한다. 사후 선택임을 표시한다.
3. 기존 WITH_SKILL1/2/3 실제 로그와 비교한다. manual/auto·Python/pip·검증 종료점 차이와6회차 승인 지연을 공개한다. 비용/속도 인과 주장은 하지 않는다.
4. 공개 응답·도구·검증만 내보내고 비공개 추론/자격증명/개인 home 경로는 제외 또는 마스킹한다. 원본 파일은 보존하고 SHA 연결한다.
5. 최신 origin/main의 별도 worktree에서 보고·측정 계획·이번 audit/state 단락만 commit/push한다. 원래 작업 폴더의 미커밋 제품/C9/웹/기존 audit 기록은 덮어쓰지 않는다. 직접 fast-forward push 전 diff/민감정보 패턴/JSON·CSV·manifest를 검사한다. 원격 진척 시 최신 변경 보존 후 재시도하며 force push하지 않는다.
6. 이것은 결과 정리와 게시 승인 범위이다. 유료 모델 재실행/제품 구현/전체 Build & Test 완료 선언은 하지 않는다. 이전 개발 마감 계획은 별도 최종 검토를 남긴다.
