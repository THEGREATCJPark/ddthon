# Agent SkillLoop

한 Agent의 해결 경험을 다음 Agent의 Skill로.

코딩 Agent가 특정 업무 환경에서 문제를 해결하며 얻은 경험을 재사용 가능한 Skill로 축적하고 공유하는 것을 목표로 합니다. 기존 경험을 활용해 반복적인 탐색을 줄이고, 새롭게 검증한 해결 방법이 다음 작업에 도움이 되도록 만들고자 합니다.

구체적인 요구사항, 구현 범위, 기술 선택과 역할 분담은 개발을 시작하며 결정합니다.

## 개발 시작

Claude Code용 공식 AI-DLC v1.0.1이 설정되어 있습니다. 저장소 루트에서 `claude`를 실행한 뒤 다음처럼 시작합니다.

```text
Using AI-DLC, README.md의 Agent SkillLoop 컨셉을 바탕으로 요구사항부터 함께 정리해 주세요.
```

모델 인증은 각자의 로컬 환경에서 설정합니다. 규칙의 버전과 라이선스는 [AI-DLC 출처](AI-DLC-SOURCE.md)를 참고하세요.
